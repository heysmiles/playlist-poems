What is Playlist Poems?

I whipped this up because I have thousands of Liked Songs that go untouched, and thought there's gotta be a good way to organize some of these songs in a unique way. Besides creative exploration, this project has no purpose :)

It's open source to try to inspire more people to use AI in creative ways — see the code on GitHub.
